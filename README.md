# 💫 About Me:
Bonjour, je suis Marine !<br><br>Je suis étudiante en 3ème année de Bachelor en ingénierie numérique (spécialisation Game Dev) à l'ISEN Méditerranée.<br><br>Créative, j'adore concevoir des expériences interactives de A à Z, que ce soit par le Game Design, la modélisation 2D/3D, le dessin mais aussi dans le développement.
